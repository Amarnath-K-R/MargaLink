# Journal Matching v2 — Implementation Plan

> **For agentic workers:** executed natively (superpowers:executing-plans), one commit per task,
> `cd web && npm run check` green before every commit; a task that touches `pipeline/` also passes
> `cd pipeline && uv run selfcheck.py && uv run ruff check .`. Steps use `- [ ]` checkboxes.

**Goal:** `/match` ranks with a measured, explained, fully on-device hybrid ranker — recent
multi-centre journal vectors, the paper's estimated OpenAlex topics, its own reference list, fused and
calibrated into a "fit %" — with published accuracy from a held-out test set.

**Architecture:** the offline pipeline re-fetches recent topic-tagged papers and journal names, builds
`index.bin` (1–4 centres per journal), `meta.json` (profiles, names, centre labels), `topics.bin/json`
and a never-deployed held-out set. One pure ranker module (`web/src/lib/rank.ts`) is run both by the
browser and by a node harness over the held-out set; the harness fits the fusion weights and
calibration and writes them, with the accuracy table, into `manifest.json`. The page adds query
transparency ("What we read"), a paste entry, topic estimates, fit badges and a "why" panel.

**Tech stack:** Python 3.11+ with numpy + sentence-transformers (no new deps; own k-means), OpenAlex
API, Next.js static export, `@huggingface/transformers` (Xenova ONNX models, 384-dim), `node`-run
`*.selfcheck.ts`, Playwright smoke.

**Spec:** Sections 1–4 above. Task 0 copies them to
`docs/superpowers/specs/2026-09-24-matching-v2-design.md` and this plan to
`docs/superpowers/plans/2026-09-24-matching-v2.md`.

## Global Constraints

- Privacy rule 1: no request on `/match` ever carries paper text, pasted text, a vector, or reference
  entries. Every request is a bodyless GET for public files. `useNetworkTrace` keeps proving it.
- Model within the small cap: 384-dim, ≤ ~70 MB browser download; switch from gte-small only for
  ≥ 5 points top-10 in the bake-off. Journal vectors and the paper vector always come from the same
  model; the manifest carries `model_id`, `dim`, `query_prefix`.
- Every file under `web/public/index/` < 25 MB (Cloudflare per-file cap); total index ≤ ~35 MB.
- No new npm dependency; no new Python dependency (numpy, sentence-transformers only).
- `src/lib/` flat, camelCase, lib-to-lib imports with `.ts`; every pure module has a `*.selfcheck.ts`
  run by plain `node`; pipeline modules each have `_self_check()` registered in `pipeline/selfcheck.py`.
- Long pipeline jobs run detached (`nohup … & disown`) from `pipeline/`, logging to the session
  scratchpad; check liveness with `ps aux | grep -E "fetch_works\.py" | grep -v grep` (never `pgrep
  -f`); relaunch only one instance (memory: pipeline-background-jobs).
- Pipeline outputs stay gitignored (`pipeline/data/*`, `web/public/index/*`).
- Commits: `Matching v2 (n/12): <what>`; push; never merge to `main`.

## Review Focus

1. **A paper with no "Abstract" heading** (preprint, letter, structured abstract with "Summary") →
   the query still embeds sensible text, and the page says the abstract wasn't found. Pinned in
   Task 6 (`matchQuery` selfcheck: fallback window strips affiliation/email lines; `source: "fallback"`).
2. **Reference entries in the three common styles** — Vancouver with dotted abbreviations
   ("N. Engl. J. Med. 2019;380:1–2"), APA ("*Journal of Applied Ecology*, 56(3)"), Nature ("Nature
   **591**, 1–5 (2021)") — and the traps ("Science" inside a title, "Cell" as a word, "Journal of
   Physics A" vs "B") → the right journals are counted, the traps aren't. Pinned in Task 5.
3. **A sparse journal** (10 papers, duplicates, all-identical vectors) → k-means never crashes, k
   collapses to 1, coherence is defined. Pinned in Task 2.
4. **A manifest without a fitted `ranking` block** (interim build, or an old cached manifest) → the
   browser uses defaults, shows fit as "unfitted" (no fake percentages), never throws. Pinned in
   Tasks 4 and 9.
5. **Filters that exclude every cited journal, or an empty candidate set** → an empty result with the
   existing "No journals match these filters" message; a cited journal that fails a filter never
   appears. Pinned in Task 4.

### `RankingConfig` (`manifest.ts`)

```ts
export type RankingConfig = {
  version: 2;
  query: "abstract" | "title-mix";           // title-mix: normalize(0.3·emb(title) + 0.7·emb(abstract))
  weights: { emb: number; topic: number; ref: number; prior: number };
  topicTop: number;                          // topics kept in the estimate (10)
  topicTemperature: number;                  // softmax temperature over cosines (0.05)
  calibration: { edges: number[]; probs: number[] }; // fused score → P(true journal), piecewise linear
  bands: { strong: number; possible: number };       // on P: ≥ strong → "strong", ≥ possible → "possible"
  fitted: boolean;
  accuracy: { n: number; top1: number; top5: number; top10: number; field1: number; byField: Record<string, { n: number; top10: number }> } | null;
};
export const DEFAULT_RANKING: RankingConfig = { version: 2, query: "abstract", weights: { emb: 1, topic: 0, ref: 0, prior: 0 }, topicTop: 10, topicTemperature: 0.05, calibration: { edges: [0, 1], probs: [0, 1] }, bands: { strong: 0.6, possible: 0.25 }, fitted: false, accuracy: null };
export function validateRanking(v: unknown): RankingConfig; // returns DEFAULT_RANKING (fitted:false) for anything malformed
```

### `rank.ts`

```ts
export type TopicEstimate = { id: string; name: string; subfield: string; share: number };
export type RankInput = {
  queryInt8: Int8Array; dim: number;
  centres: Int8Array;                        // index.bin
  meta: JournalMeta[];                       // meta.json (v2 fields)
  candidates: number[];                      // journal indices passing the filters
  paperTopics: TopicEstimate[];              // from topics.ts
  topicSubfield: Map<string, string>;        // topic id → subfield name (from topics.json)
  cited: Map<string, number>;                // journal id → citation count (references.ts), empty when none
  k: number;
};
export type Why = { topics: { id: string; name: string; paperShare: number; journalShare: number }[]; cited: number; centre: { cos: number; label: string } };
export type RankedJournal = JournalMeta & { fit: number | null; band: "strong" | "possible" | "weak" | "unfitted"; fused: number; signals: { emb: number; topic: number; ref: number; prior: number }; why: Why };
export function bestCentre(queryInt8, centres, dim, start, count): { cos: number; centre: number };
export function topicScore(paperTopics, journalTopics: [string, number][], topicSubfield): { score: number; shared: Why["topics"] };
export function refScore(cited: number, maxCited: number): number;      // log1p(c)/log1p(max), 0 when max=0
export function priorScore(m: JournalMeta, now: number): number;         // 0.5·clamp(log10(works)/5) + 0.5·(last year ≥ now-2)
export function fuse(signals, weights): number;
export function calibrate(fused: number, cal: RankingConfig["calibration"]): number;  // piecewise linear, clamped
export function rankJournals(input: RankInput, cfg: RankingConfig): RankedJournal[];
// candidates = top-200 by emb among input.candidates ∪ {cited journals ∈ input.candidates}; sorted by fused desc; first k.
```

export type NameIndex = { byFirstToken: Map<string, { tokens: string[]; ids: string[] }[]> };

### Harness CLI

```
node scripts/eval_match.ts [--sample 5000] [--seed 1] [--refs] [--fit] [--write-manifest]
  reads web/public/index/{manifest,meta,index.bin,topics.bin,topics.json}, pipeline/data/heldout.{bin,json}, drift_sample.json, [heldout_refs.json]
  prints: ladder table (top1/top5/top10/MRR/field1 per config) + per-field top10 + topic-estimate hit rates
  --fit: grid over weights on half A (emb ∈ {1}, topic ∈ {0,.25,.5,1,2}, ref ∈ {0,.25,.5,1}, prior ∈ {0,.05,.1,.2}; query ∈ {abstract,title-mix} when title vectors exist), calibration bins on half B (20 quantile bins of fused score → hit rate, monotone-smoothed)
  --write-manifest: writes ranking {weights, calibration, query, fitted:true, accuracy} into manifest.json
  drift: asserts rankJournals (weights emb-only) reproduces drift_sample.json exactly; exits 1 otherwise
```

## Risks and deferred

- **Held-out leakage:** papers 101–200 of the *old* fetch overlap the new fetch's recent window; the interim (Task 3/8) numbers are provisional and say so; only Task 11's numbers are published.
- **Topic estimate quality:** if top-3 topic hit rate on held-out is < 50%, the fitted `weights.topic` will simply come out near 0 — the harness protects the ranking, and the "Your paper's topics" line is hidden when `weights.topic === 0`.
- **Reference parsing on real PDFs:** column breaks and hyphenation split entries; the count is a floor, and the harness's reference sample assumes perfect parsing — both stated in the docs.
- **Bake-off time and model availability:** ~1 h per model; a candidate without a 384-dim Xenova build is skipped, never substituted.
- Deferred: click-a-topic to re-rank; topic browser; per-journal "recent scope" text; JANE-style "similar papers" view.
